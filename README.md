# sales-analytics-sql
# 📊 Sales Analytics using MySQL

## Overview
This project is a SQL-based retail sales analytics system developed using MySQL. It demonstrates how SQL can be used to design a relational database, analyze sales data, and generate business insights from customer transactions.

---

## Database Schema

The database consists of three normalized tables:

- **Customers** – Stores customer information.
- **Products** – Stores product details and prices.
- **Orders** – Stores order transactions and links customers with products using foreign keys.

---

## Features

- Designed a normalized relational database
- Implemented Primary Keys and Foreign Keys
- Performed business analysis using SQL
- Used JOINs to combine multiple tables
- Applied Aggregate Functions
- Used GROUP BY and HAVING
- Implemented Window Functions (RANK)
- Created Views for reporting
- Added Indexes for query optimization

---

## Business Insights Generated

- Total Revenue
- Average Order Value
- Monthly Revenue Trend
- Top Customers
- Best Selling Products
- Category-wise Revenue
- City-wise Revenue
- Repeat Customers
- Running Revenue Analysis
